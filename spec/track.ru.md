# Трек: сетевые профили

Статус: **ЧЕРНОВИК**, 2026-09-27 (имена команд обновлены по принятой форме командной строки). Спецификация: `spec/network-profiles.md` (черновик, N1–N14, учтены два независимых ревью). Роадмап: веха M7, после архивации agents-infra (решение оператора 2026-09-23: сеть идёт после launch profiles).

## Зачем

Нескольким агентам на одной машине нужно выходить в сеть через разные выходы уровня приложения (VPN A, VPN B, корпоративный прокси). При этом нельзя менять ни оркестратор, ни соседних агентов, ни операционную систему.

## Что строим

- Библиотеку `curator-network-profiles` (собственный публичный репозиторий; ей пользуются task-board и публичный `curator-run`): `resolve → validate → conditional probe → patch`; direct и планы/сухие запуски пропускают все пробы (tcp/connect/tls = `skipped`).
- `--network <name>` у `curator run` и `task-board spawn` (`task-board claude|codex` — псевдонимы `curator run`); значения по умолчанию из слоя оператора (выбор агентов) и привязок сред выполнения; сетевые профили машины в `~/.curator/network.toml`, которыми управляет провайдер Curator `curator-network` (`curator network list|show|add|remove|check [--probe]|confirm|exec`).
- Патч применяет хост, который создаёт процесс (`unset`, затем `set` для профилей прокси; direct содержит только unset, без set), и никогда через общее окружение; привязки сравниваются по дайджесту; возобновление при изменившемся профиле отклоняется.

## Интеграция

Как каждый владелец процесса применяет патч, где записывается привязка и как отклоняется возобновление при изменившемся профиле: `docs/integration-contract.md` (rev 2 принят (operator decision, 2026-10-02); реализация потребителями остаётся ЧЕРНОВИКОМ; сбор советов закрыт 2026-10-01T16:00Z). Нормативные правила дайджеста, `EnvPatch` и равенства — в `spec/contract-appendix.md`, поставленном с N-A.

## Зависимости

По operator decision (2026-10-02 07:21Z) N-C1 разделён: N-C1a (запуск субагентов) нужны только типизированный хук плоскости запуска (D4) + v0.2.0; N-C1b (хосты сессий) следует после M3 / LP Phase 0.
